Sistema de Gestión Comercial — Guía completa de uso y operación

📅 Julio 2026 📄 Versión 1.0 🔒 Uso interno

1 Introducción

El Sistema de Gestión Comercial es una plataforma integral diseñada para administrar las operaciones diarias de negocios comerciales. Proporciona herramientas para el control de inventario, registro de ventas y compras, gestión de clientes con programa de fidelización, y generación de reportes ejecutivos.

1.1 Módulos del Sistema

1.2 Roles de Usuario

El sistema contempla dos roles con distintos niveles de acceso:

AdministradorAcceso completo a todas las funcionalidades, incluyendo gestión de usuarios
UsuarioAcceso a operaciones diarias (ventas, compras, productos) sin administración de cuentas

3 Acceso al Sistema

3.1 Inicio de Sesión

Para acceder al sistema, utilice el formulario de inicio de sesión:

  1. Ingrese su nombre de usuario en el campo correspondiente.
  2. Ingrese su contraseña personal.
  3. Presione el botón "Iniciar Sesión".

3.2 Credenciales por Defecto

Al realizar la instalación inicial, se crea automáticamente una cuenta de administrador:

CampoValor
Usuarioadmin
Contraseñaadmin123
⚠️ Importante: Cambie la contraseña por defecto inmediatamente después del primer inicio de sesión.

3.3 Recuperación de Contraseña

Si olvida su contraseña, contacte al administrador del sistema para restablecerla. Por razones de seguridad, no es posible recuperar contraseñas de forma automática.

5 Panel Principal (Dashboard)

Una vez iniciada la sesión, el Dashboard se muestra como pantalla principal.

5.1 Indicadores Clave (KPI)

El panel superior muestra tarjetas con indicadores en tiempo real:

📦 ProductosTotal de productos activos en el catálogo
👥 ClientesNúmero total de clientes registrados
🧾 Ventas HoyTotal de ventas realizadas en el día actual
💰 Ingresos HoySuma total de ingresos generados en el día
💡 Cada tarjeta es un enlace directo a la sección correspondiente. Al hacer clic en "Productos", el sistema lo redirige al módulo de productos.

5.2 Secciones del Dashboard

  • Ventas Recientes: Lista las últimas transacciones realizadas con información de cliente, productos, total, método de pago y fecha.
  • Productos con Stock Bajo: Alerta visual de productos cuyo inventario está por debajo del límite mínimo. Incluye acceso directo para realizar una orden de compra.
  • Productos Más Vendidos: Ranking de productos con mayor volumen de ventas en el período reciente.

5.3 Barra de Navegación Lateral

El menú lateral izquierdo proporciona acceso a todos los módulos del sistema:

  • 🏠 Inicio → Dashboard
  • 📦 Productos → Gestión de catálogo
  • 📂 Categorías → Clasificación de productos
  • 🚚 Proveedores → Directorio de proveedores
  • 👥 Clientes → Base de datos de clientes
  • 🧾 Nueva Venta / Ventas → Módulo de ventas
  • 📥 Compras → Registro de compras
  • 📊 Reportes → Análisis y estadísticas
  • 🔐 Usuarios → Administración (solo administradores)
  • 👤 Perfil → Configuración personal

En la parte inferior del menú se encuentra el botón "Cerrar Sesión".

6 Gestión de Productos

6.1 Catálogo de Productos

El módulo de productos permite administrar el inventario completo del negocio. Al ingresar, se muestra una tabla con todos los productos registrados.

6.2 Registrar un Nuevo Producto

  1. Haga clic en el botón "Nuevo Producto" en la parte superior derecha.
  2. Complete el formulario con los datos requeridos.
  3. Presione "Guardar" para registrar el producto.

6.3 Editar un Producto

Ubique el producto en la tabla, haga clic en el ícono de lápiz (editar), modifique los campos necesarios y presione "Guardar Cambios".

6.4 Eliminar un Producto

Haga clic en el ícono de papelera (eliminar) y confirme en el cuadro de diálogo.

⚠️ Eliminar un producto es una acción irreversible. Considere desactivarlo en lugar de eliminarlo si existe historial de ventas asociado.

6.5 Búsqueda de Productos

Utilice el campo de búsqueda en la parte superior de la tabla para filtrar productos por nombre. La búsqueda se realiza en tiempo real mientras escribe.

6.6 Alerta de Stock Bajo

El sistema muestra una indicación visual (color rojo) en los productos cuyo stock actual sea menor o igual al stock mínimo configurado.

7 Gestión de Categorías

7.1 Clasificación de Productos

Las categorías permiten organizar los productos por rubro o tipo, facilitando su localización y generación de reportes.

7.2 Operaciones Disponibles

  • Crear: Haga clic en "Nueva Categoría", ingrese el nombre y presione "Guardar".
  • Editar: Haga clic en el ícono de editar, modifique el nombre y presione "Guardar Cambios".
  • Eliminar: Haga clic en el ícono de eliminar y confirme la acción.
📌 Al eliminar una categoría, los productos asignados a ella quedarán sin categoría, pero no se eliminarán.

8 Gestión de Proveedores

8.1 Directorio de Proveedores

Módulo destinado a registrar y administrar los proveedores del negocio.

8.2 Registrar un Proveedor

  1. Haga clic en "Nuevo Proveedor".
  2. Complete los campos: Nombre (obligatorio), Contacto, Teléfono, Email y Dirección.
  3. Presione "Guardar".

8.3 Editar y Eliminar Proveedores

Utilice los íconos de acción en la tabla para editar o eliminar proveedores, siguiendo el mismo procedimiento que con productos y categorías.

9 Gestión de Clientes

9.1 Base de Datos de Clientes

El sistema cuenta con un módulo completo para la administración de clientes, incluyendo historial de compras y un sistema de fidelización basado en puntos.

9.2 Registrar un Cliente

Registro Completo

  1. Acceda al módulo Clientes desde el menú lateral.
  2. Haga clic en "Nuevo Cliente".
  3. Complete los datos: Nombre (obligatorio), Email, Teléfono, Dirección, Tipo de Documento y Número de Documento.
  4. Presione "Guardar".

Registro Rápido desde Ventas

Durante el proceso de venta, es posible registrar un cliente de forma expresa:

  1. Active la opción "Buscar Cliente" en la pantalla de venta.
  2. Si el cliente no está registrado, haga clic en "Registrar Cliente".
  3. Ingrese únicamente el nombre (obligatorio) y teléfono (opcional).
  4. El cliente se registra y selecciona automáticamente en la venta actual.

9.3 Sistema de Puntos de Fidelidad

Concepto

El sistema de puntos premia la lealtad de los clientes frecuentes. Por cada compra realizada, el cliente acumula puntos que pueden ser canjeados por descuentos en compras futuras.

Acumulación1 punto por cada S/ 100.00 de compra
Valor del Punto1 punto = S/ 1.00 de descuento
Uso MáximoHasta el 100% de los puntos disponibles
⭐ Consejo: En el módulo de Clientes, cada tarjeta muestra los puntos acumulados. Durante una venta, al seleccionar un cliente, el panel muestra sus puntos disponibles y permite canjearlos con un control deslizante.

10 Módulo de Ventas

10.1 Descripción General

El módulo de ventas es el corazón del sistema. Permite registrar transacciones comerciales de forma rápida y eficiente, con soporte para múltiples formas de pago y gestión de clientes.

10.2 Flujo de Venta

Paso 1: Configuración del Cliente

Al hacer clic en "Nueva Venta", se presentan dos opciones:

Venta DirectaNo requiere registrar un cliente. Ideal para transacciones rápidas.
Venta con ClienteBusque un cliente registrado o regístrelo rápidamente desde la venta.

Paso 2: Agregar Productos

  1. En el campo de búsqueda de productos, escriba el nombre del producto.
  2. Seleccione el producto de la lista desplegable.
  3. Configure la cantidad a vender.
  4. Haga clic en "Agregar" o presione Enter.

Paso 3: Revisar el Carrito

El carrito de compras muestra el nombre del producto, precio unitario, cantidad, subtotal y un botón para eliminar productos. Use los botones + y − para ajustar cantidades directamente desde el carrito.

Paso 4: Aplicar Puntos de Fidelidad

Si la venta está asociada a un cliente con puntos acumulados:

  • Se mostrará un control deslizante en el panel de cliente.
  • Arrastre el deslizador o ingrese manualmente la cantidad de puntos a canjear.
  • El descuento se reflejará automáticamente en el total.

Paso 5: Seleccionar Tipo de Pago

Seleccione el método de pago: Efectivo Tarjeta Transferencia Crédito

Paso 6: Completar la Venta

Presione "Cobrar" y el sistema registrará automáticamente:

  • Descuento del stock de productos vendidos.
  • Acumulación de puntos de fidelidad (si aplica).
  • Registro en el historial de ventas.

10.4 Detalle de Venta

Al hacer clic en "Ver Detalle" se muestra: información del cliente, productos vendidos, puntos ganados y utilizados, método de pago, fecha y hora.

10.5 Anulación de Ventas

  1. Localice la venta en el historial.
  2. Haga clic en el ícono de anular (✕).
  3. Confirme la anulación.
  4. El sistema revertirá automáticamente el stock de los productos.
⚠️ La anulación de ventas es irreversible. Solo los administradores pueden anular transacciones.

11 Módulo de Compras

11.1 Propósito

El módulo de compras permite registrar las órdenes de reposición de inventario, actualizando automáticamente el stock de los productos.

11.2 Registrar una Compra

  1. Haga clic en "Nueva Compra".
  2. Seleccione el proveedor de la lista desplegable.
  3. Agregue productos al listado de compra: seleccione el producto, ingrese la cantidad y verifique el precio.
  4. Confirme la compra presionando "Guardar".

11.3 Efectos de una Compra

  • El stock de los productos seleccionados se incrementa automáticamente.
  • Se registra un movimiento en el historial de compras.
  • Se actualiza el precio de compra si se modificó durante el registro.

12 Reportes y Estadísticas

12.1 Panel de Reportes

El módulo de reportes proporciona herramientas de análisis para la toma de decisiones gerenciales.

12.2 Tipos de Reportes

📈 Reporte de VentasIngresos por período, ventas por día/semana/mes, comparativas, ventas por tipo de pago, descuentos por puntos
📦 Reporte de ProductosProductos más vendidos, menor rotación, valor del inventario, margen de ganancia
👥 Reporte de ClientesClientes con más compras, más puntos acumulados, historial por cliente

12.3 Uso del Filtro de Fechas

Para todos los reportes, puede definir un período específico:

  1. Utilice el selector de fechas en la parte superior del panel.
  2. Seleccione la fecha de inicio y fecha de fin.
  3. Presione "Filtrar" para actualizar los datos.
  4. O use los botones de acceso rápido: Hoy Esta Semana Este Mes Este Año

15 Exportación de Datos

15.1 Formatos Soportados

📄 CSVProcesamiento en hojas de cálculo (Excel, Google Sheets)

16 Solución de Problemas Frecuentes

16.1 No puedo iniciar sesión

ProblemaSolución
Usuario o contraseña incorrectosVerifique que ambos campos estén escritos correctamente (distingue mayúsculas/minúsculas)
Cuenta bloqueadaContacte al administrador del sistema
Sesión expiradaCierre el navegador y vuelva a iniciar sesión

16.2 No aparecen productos al vender

  • Aún no se han registrado productos en el catálogo.
  • Los productos tienen stock en cero (configure stock mínimo para recibir alertas).
  • El filtro de búsqueda está activo (limpie el campo de búsqueda).

16.3 El stock no se actualiza

Verifique que la venta o compra se haya guardado correctamente. Si una venta fue anulada, el stock se restablece automáticamente. Si el problema persiste, contacte al administrador.

16.4 No puedo eliminar un usuario

Verifique que no está intentando eliminar su propio usuario y confirme que tiene rol de Administrador.

16.5 Los puntos de fidelidad no se aplican

  1. La venta debe estar asociada a un cliente registrado.
  2. El cliente debe tener puntos disponibles.
  3. El control deslizante debe estar activado durante la venta.
  4. Los puntos aplicados no pueden exceder el total de la venta.

16.6 Error al exportar a PDF

Asegúrese de que su navegador permita descargas emergentes (pop-ups). Intente con otro navegador. Si el archivo se descarga pero no se abre, instale un lector de PDF.
